# Phase 2 freeze — v1.5

Phase 2 is frozen as a limited visual patchability prototype.

## What Phase 2 includes

- Selectable input source:
  - LFO
  - Noise
  - Manual CV
- Visual destination selector:
  - Scope
  - Filter cutoff placeholder
  - Pitch placeholder
  - Level placeholder
- Read-only patch summary panel.
- Existing S&H, T&H, and Super S&H visual hold modes.

## What Phase 2 does not include

- No audio.
- No free patch cables.
- No real destination routing.
- No VCO sound.
- No VCF sound.
- No VCA sound.
- No presets.
- No save/load.
- No VCV Rack.
- No Tauri.
- No quantising.
- No probability.
- No burst sampling.
- No external MIDI/CV input.
- No modulation matrix.
- No multiple simultaneous destinations.

## Freeze statement

Phase 2 is good enough when the user can choose what the S&H samples, choose a visual destination label, and read a plain summary of the current visual patch.

Later phases are not being built yet.
