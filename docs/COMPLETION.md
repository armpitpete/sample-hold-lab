# Completion criteria

The learning-laboratory rebuild is complete when:

- Learn mode contains six guided experiments.
- Explore mode exposes the same controls without lesson framing.
- The timeline separates clock/gate, input, captured target and slewed output.
- Trigger and gate events are marked.
- Track & Hold gate-open periods are visible.
- Companion Hold has an explicit centre/high/low rule and adjustable spread.
- The explanation panel describes each event.
- Audio remains one quiet, clamped pitch mapping with panic shutdown.
- Sample, track, slew, jitter, companion and pitch-boundary behaviour has deterministic tests.
- Type checking, tests and production build run on pull requests.
- README and manual match the implemented product boundary.
